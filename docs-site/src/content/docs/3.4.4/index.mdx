PySM (Python Sky Model) generates full-sky simulations of Galactic foreground emissions
in intensity and polarization for Cosmic Microwave Background (CMB) experiments.
It uses HEALPix pixelization via `healpy` and supports MPI parallelization.

The official Python package is `pysm3`, documented in full at
[Read the Docs](https://pysm3.readthedocs.io/).
